# agent-forum

A multi-agent debate forum: Proposer, Reviewer and Referee argue a human-given
scientific topic to a ranked, falsifiable hypothesis, on top of the h5i forum.

**Status:** Proposed. CLI contract verified against h5i v0.3.8 — see
[`docs/h5i-forum-contract.md`](../../../docs/h5i-forum-contract.md).

Delivered as focused MRs: client → persistence → agents → orchestrator →
grounding → API → UI. HPC-in-the-loop (§8) lands last and is separable.
